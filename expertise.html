Data quality & identity resolution

FReD (Frequency, Recency, Duration): a patent-pending model that collapses the many addresses, phones and emails tied to one consumer, each with its own timestamps, some correct and some as entered, into a ranked, scored, deduplicated list of true uniques. One well-written address instead of the same address malformed 14 times. Just as important, I set the standards that cleaned and validated PII before it reached the discovery service, so identity resolution received the right input combinations to find the best key.
